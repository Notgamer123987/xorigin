03 — How to Use (Step by Step)
1
Host on GitHub Pages
Upload both index.html and victim.html to a GitHub repo. Go to Settings → Pages → set source to main branch. Your tool will be live at https://yourusername.github.io/reponame/
2
Open the dashboard (this page)
Navigate to your GitHub Pages URL. This is your attacker dashboard — it listens for data in real time.
3
Configure your target
Paste the vulnerable API endpoint URL. Set method to GET (most common for CORS leaks). Check Include credentials if the endpoint requires login. Set redirect to any site — victim lands there after payload fires.
4
Generate the victim link
Click Generate victim link. This creates a unique URL pointing to victim.html with all parameters encoded. Click the green box to copy it.
5
Simulate the victim (for PoC)
While logged into the target site in the same browser, open the victim link in a new tab. The page fires the CORS request silently and redirects. Keep the dashboard tab open — data arrives automatically.
6
Screen record and submit
Record the full flow — dashboard open, victim link opened in new tab, data appearing in the Captured Data panel. This is your video PoC. Submit it with the report on Intigriti/HackerOne.
04 — Ethical Use Policy

This tool is built exclusively for bug bounty research and authorized security testing. By using it, you agree to the following:

✓  Only test endpoints on programs where you have explicit written authorization — active bug bounty programs, your own infrastructure, or private scopes you are invited to.
✓  Do not use the victim link to target real users without their knowledge outside of a controlled PoC demo you run yourself.
✓  Do not use this tool to extract, store, or share real user PII beyond what is minimally necessary to demonstrate vulnerability impact in your report.
✓  Disclose all findings responsibly through the program's official channel — Intigriti, HackerOne, Bugcrowd, or direct vendor disclosure. Do not publish before a fix is deployed.
✓  Delete any captured sensitive data after your report is submitted and acknowledged.

This tool performs no persistent storage, no external data exfiltration, and sends no data to any server. All communication happens locally in your browser via BroadcastChannel. The code is fully readable — audit it yourself.
